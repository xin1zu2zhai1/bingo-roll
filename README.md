# ビンゴ ロール（親機）

数字を引く画面です。`index.html` 1ファイルで動きます。

1. このリポジトリを GitHub に push し、Settings → Pages で `main` ブランチ / `/(root)` を公開
2. 画面上部の **認証番号（6桁）** を参加者に伝える
3. `ROLL` ボタン（またはスペースキー）で数字を引く

- 参加者のリーチ・ビンゴは右側の一覧とポップアップで通知されます（判定はロール側でカードの数字から再計算するので、不正な申告は反映されません）
- 「1つ戻す」：引き間違いの取り消し / 「新しいゲーム」：同じ番号のままリセット（カードは配り直し） / 「認証番号を変更」：別の番号で新規開始
- ページを再読み込みしても状態はブラウザに保存されています

## 設定（`index.html` の先頭）
- `CARD_PAGE_URL`：カードページの公開URLを入れると、参加用リンクとQRコードが表示されます
- `APP_NS` / `BROKER_URL`：カード側と必ず同じ値にしてください

## 参加者のリセット
- 抽選・参加などの操作が `SESSION_TTL_HOURS`（初期値6時間）ないと、自動で新しい認証番号に切り替わり、参加者一覧もリセットされます（開いたまま放置しても、再読み込みしても同じ）
- 「新しいゲーム」を押すと、その時点でオフラインの参加者は一覧から外れます（戻ってきたら自動で再参加）
- 参加者一覧の「×」で個別に外せます（その人のカード画面は参加画面に戻ります）
